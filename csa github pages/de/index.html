Ihre Daten bleiben auf Ihrem Gerät

Die Anwendung speichert Daten im von Ihnen gewählten lokalen Ordner. Schützen Sie Dateien und Sicherungen. Support-E-Mails erreichen den Entwickler nur, wenn Sie sie absenden.

Häufige Fragen

Ist Car Service Archiver kostenlos?

Ja. Die erste Windows-Version von Car Service Archiver ist kostenlos im Microsoft Store verfügbar.

Wo werden die Daten gespeichert?

Kunden-, Fahrzeug- und Servicedaten werden im selbst gewählten lokalen Ordner gespeichert. Datensicherungen lassen sich verwalten.
