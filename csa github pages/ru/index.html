Программа сохраняет записи в выбранной локальной папке. Защищайте файлы и резервные копии. Письма разработчику поступают только при вашей отправке.

Частые вопросы

Car Service Archiver бесплатен?

Да. Первый выпуск для Windows планируется бесплатно разместить в Microsoft Store. Ссылка появится после публикации.

Где хранятся данные?

Данные о клиентах, автомобилях и обслуживании сохраняются в выбранной локальной папке; резервными копиями можно управлять.
