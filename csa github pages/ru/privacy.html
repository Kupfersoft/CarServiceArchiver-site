Политика конфиденциальности

Обновлено: 27 октября 2026 г. · Бесплатная версия для Windows · v1.0

Политика касается бесплатной программы Car Service Archiver для Windows и этого сайта. KupferSoft — бренд независимого разработчика, а не зарегистрированная компания. Контакт: carservicearchiver.support@gmail.com.

1. Хранимые данные

Имена, контакты, автомобили, номера, работы, даты, пробег, детали, заметки и фото могут содержать персональные данные. Они хранятся в локальной базе SQLite и файлах в выбранной папке; некоторые настройки тоже остаются на устройстве.

2. Автоматическая передача

В текущем проекте v35 нет функции автоматической отправки базы клиентов или фотографий разработчику. Сетевой доступ ограничен, однако работа ОС и сторонних сервисов не позволяет гарантировать полное отсутствие передач.

3. Экспорт и копии

Резервное копирование, восстановление, CSV и PDF используют указанные пользователем папки. Облачная синхронизация или добровольное предоставление файлов может передавать данные. Удаление записи не стирает ранее созданные копии.

4. Письма в поддержку

Приложение открывает вашу почтовую программу, решение отправить письмо принимает пользователь. Базы и фотографии автоматически не прикладываются. Адрес, тема, текст, добровольные вложения и переписка могут обрабатываться для ответа. Почта работает через Gmail; конкретный срок хранения и правовое основание нужно определить до публикации.

5. Хостинг и третьи стороны

Сайт подготовлен для GitHub Pages, без собственной аналитики, рекламы и трекеров. GitHub может обрабатывать IP-адреса и технические журналы; Microsoft обрабатывает данные получения из Store по своим правилам.

GitHub · Microsoft

6. Ответственность

Автосервис, решающий цели и сроки хранения данных клиентов, сам оценивает свои обязанности. Предоставление программы не делает разработчика автоматически ответственным за все записи клиентов. Обращения в поддержку обрабатываются отдельно.

7. Права и запросы

Запросы на доступ, исправление или удаление переписки направляйте на carservicearchiver.support@gmail.com; они рассматриваются по применимому праву. По записям клиентов обращайтесь к соответствующему автосервису.

8. Безопасность и изменения

Защищайте папку данных, учётную запись и резервные копии. Политика может обновляться; дата указана выше.
