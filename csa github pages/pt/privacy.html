Informações legais e de privacidade

Política de privacidade

Última atualização: 27 de outubro de 2026 · Versão gratuita para Windows · v1.0

Esta política abrange o Car Service Archiver, aplicação Windows gratuita, e este site. KupferSoft é uma marca de um programador independente, não uma empresa registada. Contacto: carservicearchiver.support@gmail.com.

1. Dados guardados

Nomes, contactos, veículos, matrículas, serviços, datas, quilometragem, peças, notas e fotografias podem conter dados pessoais. São guardados numa base SQLite e ficheiros locais na pasta selecionada. Algumas definições também ficam no dispositivo.

2. Transferências automáticas

A conceção atual da versão v35 não inclui envio automático de bases de clientes ou fotografias ao programador. A aplicação limita ligações de rede, mas não garante o comportamento de sistemas operativos ou terceiros.

3. Exportações e cópias

Cópias, restauros, exportações CSV e PDF utilizam pastas escolhidas pelo utilizador. Uma pasta sincronizada com a nuvem ou partilha voluntária pode transferir os dados. Apagar registos não elimina automaticamente cópias anteriores.

4. E-mails de suporte

A aplicação abre o seu programa de e-mail; cabe-lhe enviar a mensagem. Não anexa automaticamente bases ou fotografias. Endereço, assunto, mensagem, anexos voluntários e histórico podem ser usados para responder. A caixa utiliza Gmail; os prazos concretos e a base legal devem ser definidos antes da publicação.

5. Alojamento e terceiros

Site preparado para GitHub Pages, sem analítica, publicidade nem rastreadores próprios. O GitHub pode processar endereços IP e registos técnicos. O Microsoft Store trata dados de aquisição segundo a sua política.

GitHub · Microsoft

6. Responsabilidades

A oficina que determina a finalidade e a conservação dos dados dos seus clientes deve avaliar as suas obrigações. Fornecer software não torna automaticamente o programador responsável por esses registos. Os e-mails de suporte são tratados à parte.

7. Direitos e pedidos

Para acesso, correção ou eliminação de correspondência de suporte, escreva a carservicearchiver.support@gmail.com. Os pedidos seguem a legislação aplicável. Para dados de clientes, contacte a oficina responsável.

8. Segurança e alterações

Proteja a pasta, a conta do dispositivo e as cópias. Esta política pode ser atualizada; consulte a data de revisão.
