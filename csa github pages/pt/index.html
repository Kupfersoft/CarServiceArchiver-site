Os seus dados ficam no dispositivo

A aplicação guarda os registos na pasta local que escolher. Proteja os ficheiros e as cópias de segurança. Os e-mails de suporte só chegam ao programador quando os envia.

Perguntas frequentes

O Car Service Archiver é grátis?

Sim. A primeira versão Windows do Car Service Archiver está disponível gratuitamente na Microsoft Store.

Onde ficam os registros?

Os dados de clientes, veículos e serviços são guardados numa pasta local escolhida por você. Também é possível fazer backups.
