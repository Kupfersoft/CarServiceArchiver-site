法律与隐私信息

隐私政策

更新日期：2026年10月27日 · 免费 Windows 版本 · v1.0

本政策适用于免费的 Car Service Archiver Windows 应用以及本网站。KupferSoft 是独立开发者使用的软件品牌，并非注册公司。联系邮箱：carservicearchiver.support@gmail.com。

1. 存储哪些数据

客户姓名、联系方式、车辆与车牌、维修项目、日期、里程、零件、备注和照片可能包含个人信息。数据存储在用户指定文件夹中的本地 SQLite 数据库及相关文件内，部分设置也保存在设备上。

2. 自动数据传输

当前 v35 设计中没有自动将客户数据库或维修照片发送给开发者的功能。应用限制网络连接，但不对操作系统及第三方服务的全部行为作绝对保证。

3. 导出与备份

备份、恢复、CSV 导出和 PDF 操作使用用户选择的位置。如果保存到云同步文件夹或自行分享，数据可能离开设备。删除记录不会自动删除以前创建的备份。

4. 支持邮件

应用会打开您自己的邮件程序，由您决定是否发送；不会自动附加数据库或照片。您的邮箱、主题、内容、自行添加的附件和往来邮件可能用于处理请求。邮箱使用 Gmail；具体保存期限和法律依据应在正式发布前进一步确定。

5. 网站托管与第三方

本网站为 GitHub Pages 准备，不含开发者添加的分析、广告或跟踪脚本。GitHub 可能处理 IP 地址及访问日志。Microsoft Store 的下载数据受微软的隐私声明约束。

GitHub · Microsoft

6. 责任划分

决定客户信息收集目的及保存期限的维修企业，应自行评估其隐私保护义务。仅提供软件并不意味着开发者自动成为全部客户记录的数据控制者。主动发送的支持邮件属于独立的数据处理活动。

7. 查询与删除请求

如需查询、更正或删除支持邮件记录，请发送邮件至 carservicearchiver.support@gmail.com。请求将按照适用法律处理。有关企业客户记录，请联系管理该记录的维修企业。

8. 安全与变更

请妥善保护数据文件夹、设备账户和备份。功能或数据处理方式变化时，本政策可能更新；修订日期见上方。
