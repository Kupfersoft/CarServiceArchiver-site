Domande frequenti

Car Service Archiver è gratuito?

Sì. La prima versione per Windows sarà pubblicata gratuitamente su Microsoft Store. Il link verrà aggiunto dopo il lancio.

Dove vengono salvati i dati?

I dati di clienti, veicoli e interventi sono progettati per restare nella cartella locale scelta dall’utente. Puoi anche gestire i backup.
