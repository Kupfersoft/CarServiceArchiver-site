Tez-tez verilən suallar

Car Service Archiver pulsuzdur?

Bəli. İlk Windows versiyasının Microsoft Store-da pulsuz yayımlanması planlaşdırılır. Yayımlandıqdan sonra yükləmə keçidi əlavə olunacaq.

Qeydlər harada saxlanılır?

Müştəri, avtomobil və servis qeydləri seçdiyiniz yerli qovluqda saxlanılmaq üçün hazırlanıb. Ehtiyat nüsxələrini də idarə edə bilərsiniz.
