Hüquqi və məxfilik məlumatları

Məxfilik siyasəti

Son yenilənmə: 27 oktyabr 2026 · Pulsuz Windows versiyası · v1.0

Bu siyasət pulsuz Car Service Archiver Windows tətbiqinə və bu sayta aiddir. KupferSoft müstəqil tərtibatçının proqram markasıdır, qeydiyyatlı şirkət deyil. Əlaqə: carservicearchiver.support@gmail.com.

1. Saxlanan məlumatlar

Müştəri adı, əlaqə, avtomobil, nömrə nişanı, servis işləri, tarixlər, yürüş, ehtiyat hissələri, qeydlər və fotolar şəxsi məlumat ola bilər. Onlar seçilmiş qovluqdakı lokal SQLite bazasında və fayllarda saxlanır. Bəzi ayarlar da cihazda qalır.

2. Avtomatik ötürmə

Mövcud v35 layihəsində müştəri bazasını və ya fotoları tərtibatçıya avtomatik göndərən funksiya yoxdur. Şəbəkə bağlantıları məhdudlaşdırılır, lakin əməliyyat sistemi və üçüncü tərəflərin bütün ötürmələri barədə mütləq zəmanət verilmir.

3. İxrac və ehtiyat nüsxələr

Yedəkləmə, bərpa, CSV ixracı və PDF əməliyyatları istifadəçinin seçdiyi yerlərdən istifadə edir. Buludla sinxron qovluq və könüllü paylaşma məlumatları ötürə bilər. Qeydi silmək əvvəlki nüsxələri avtomatik silmir.

4. Dəstək məktubları

Tətbiq sizin e-poçt proqramınızı açır; göndərmək qərarı sizindir. Baza və fotolar avtomatik əlavə edilmir. Ünvan, mövzu, məktub, əlavə etdiyiniz fayllar və yazışma cavab vermək üçün işlənə bilər. Poçt Gmail üzərindədir; dəqiq saxlama müddəti və hüquqi əsas dərcdən əvvəl müəyyənləşdirilməlidir.

5. Sayt və üçüncü tərəflər

Sayt GitHub Pages üçün hazırlanıb; öz analitika, reklam və izləmə kodu yoxdur. GitHub IP və texniki jurnalları işləyə bilər. Microsoft Store məlumatları Microsoft-un siyasəti ilə tənzimlənir.

GitHub · Microsoft

6. Məsuliyyət bölgüsü

Müştəri məlumatlarının məqsədini və müddətini müəyyən edən servis öz öhdəliklərini qiymətləndirməlidir. Proqramın təqdim edilməsi tərtibatçını avtomatik olaraq bu qeydlərin məsul şəxsi etmir. Dəstək məktubları ayrıdır.

7. Hüquqlar və müraciətlər

Dəstək yazışmalarına çıxış, düzəliş və ya silinmə üçün carservicearchiver.support@gmail.com ünvanına yazın. Müraciətlər tətbiq olunan qanuna uyğun qiymətləndirilir. Müştəri qeydləri üçün onları idarə edən servisə müraciət edin.

8. Təhlükəsizlik və dəyişikliklər

Qovluğunuzu, cihaz hesabınızı və ehtiyat nüsxələri qoruyun. Siyasət yenilənə bilər; tarix yuxarıda göstərilib.
