Informations juridiques et confidentialité

Politique de confidentialité

Dernière mise à jour : 27 octobre 2026 · Version Windows gratuite · v1.0

Cette politique concerne Car Service Archiver, logiciel Windows gratuit, et ce site. KupferSoft est une marque utilisée par un développeur indépendant, pas une société constituée. Contact : carservicearchiver.support@gmail.com.

1. Informations enregistrées

Les noms, coordonnées, véhicules, immatriculations, interventions, dates, kilométrages, pièces, notes et photos peuvent contenir des données personnelles. Ils sont stockés dans une base SQLite et des fichiers locaux au dossier choisi ; certains réglages restent aussi sur l’appareil.

2. Transferts automatiques

Dans la conception actuelle de v35, aucune fonction n’envoie automatiquement les bases de clients ou les photos au développeur. Les connexions réseau sont limitées, sans garantie absolue quant aux actions du système et des services tiers.

3. Exportations et sauvegardes

Les sauvegardes, restaurations, exports CSV et impressions PDF utilisent les emplacements choisis. Un dossier synchronisé ou un partage volontaire peut transférer les données. La suppression de fiches n’efface pas automatiquement les sauvegardes antérieures.

4. Courriels d’assistance

La fonction ouvre votre messagerie ; vous choisissez d’envoyer le courriel. Aucune base ou photo n’est jointe automatiquement. Votre adresse, le contenu, les pièces jointes choisies et les échanges peuvent être traités pour vous répondre. La boîte utilise Gmail ; la durée de conservation et la base juridique restent à préciser avant publication.

5. Hébergement et tiers

Ce site est prévu pour GitHub Pages, sans outil d’analyse, publicité ni traceur ajouté par nous. GitHub peut traiter l’adresse IP et des journaux techniques. Microsoft gère les données d’acquisition du Store selon sa politique.

GitHub · Microsoft

6. Responsabilités

L’atelier qui définit les finalités et durées de conservation des données clients doit respecter ses propres obligations. Fournir le logiciel ne rend pas automatiquement le développeur responsable de ces dossiers ; les courriels au support sont distincts.

7. Droits et demandes

Pour l’accès, la rectification ou la suppression des échanges d’assistance, écrivez à carservicearchiver.support@gmail.com. Les demandes sont examinées selon la loi applicable. Pour les dossiers clients, adressez-vous à l’atelier concerné.

8. Sécurité et modifications

Protégez le dossier local, l’ordinateur et les sauvegardes. Cette politique peut évoluer ; la date de révision figure ci-dessus.
