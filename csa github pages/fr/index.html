Vos données restent sur votre appareil

L’application est conçue pour enregistrer les dossiers dans le dossier local de votre choix. Protégez vos fichiers et sauvegardes. Les messages d’assistance ne parviennent au développeur que si vous les envoyez.

Questions fréquentes

Car Service Archiver est-il gratuit ?

Oui. La première version Windows est prévue gratuitement sur Microsoft Store. Le lien sera ajouté après sa publication.

Où sont stockées les données ?

Les dossiers clients, véhicules et interventions sont conçus pour rester dans un dossier local choisi par l’utilisateur. Des sauvegardes sont possibles.
