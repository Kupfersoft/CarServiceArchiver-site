よくある質問

Car Service Archiver は無料ですか？

はい。最初の Windows 版は Microsoft Store で無料公開する予定です。公開後にダウンロードリンクを追加します。

記録はどこに保存されますか？

顧客・車両・整備の記録は、指定したローカルフォルダーに保存する設計です。バックアップも管理できます。
