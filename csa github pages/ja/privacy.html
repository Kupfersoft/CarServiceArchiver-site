法的情報とプライバシー

プライバシーポリシー

更新日：2026年10月27日 · 無料Windows版 · v1.0

このポリシーは無料のWindowsアプリ Car Service Archiver と本サイトに適用されます。KupferSoftは個人開発者のソフトウェアブランドであり、登記された会社ではありません。連絡先：carservicearchiver.support@gmail.com。

1. 保存される情報

顧客名、連絡先、車両、ナンバープレート、作業、日付、走行距離、部品、メモ、写真には個人情報が含まれる場合があります。データは指定フォルダー内のローカルSQLiteデータベースとファイルに保存され、設定の一部も端末に残ります。

2. 自動送信について

現在のv35の設計には、顧客データベースや写真を開発者へ自動送信する機能はありません。ネットワーク接続を制限していますが、OSや第三者サービスのすべての動作について絶対的な保証はできません。

3. エクスポートとバックアップ

バックアップ、復元、CSV出力、PDF操作にはユーザーが選択した保存先を使います。クラウド同期フォルダーへの保存や共有により端末外へ転送される場合があります。記録を削除しても過去のバックアップは自動削除されません。

4. サポートメール

アプリは利用者のメールソフトを開き、送信するかどうかは利用者が決めます。データベースや写真は自動添付されません。メールアドレス、件名、本文、任意の添付ファイル、履歴を対応目的で処理する場合があります。メールにはGmailを利用し、保存期間と法的根拠は公開前に確定する必要があります。

5. サイトと第三者

本サイトはGitHub Pages向けで、独自の解析・広告・追跡コードは含みません。GitHubがIPアドレスやアクセスログを処理する場合があります。Microsoft Storeの取得情報はMicrosoftのプライバシー規定に従います。

GitHub · Microsoft

6. 責任の範囲

顧客情報の利用目的や保存期間を決める整備事業者は、自らの法的義務を確認する必要があります。ソフトウェアを提供するだけで、開発者が全顧客情報の管理者になるわけではありません。サポートメールは別の処理です。

7. 権利と請求

サポートメールについての開示、訂正、削除は carservicearchiver.support@gmail.com にご連絡ください。適用法に従って判断します。事業者の顧客記録については該当の事業者にお問い合わせください。

8. 安全管理と変更

データフォルダー、端末アカウント、バックアップを保護してください。機能や取扱いが変わる場合、ポリシーを更新します。日付は上に表示します。
