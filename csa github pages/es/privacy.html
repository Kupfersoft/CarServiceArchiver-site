Información legal y privacidad

Política de privacidad

Última actualización: 27 de octubre de 2026 · Versión gratuita para Windows · v1.0

Esta política se aplica a Car Service Archiver, aplicación gratuita para Windows, y a este sitio. KupferSoft es una marca utilizada por un desarrollador independiente, no una empresa constituida. Contacto: carservicearchiver.support@gmail.com.

1. Datos almacenados

Los registros de clientes, teléfonos, vehículos, matrículas, trabajos, fechas, kilometraje, piezas, notas y fotos pueden contener datos personales. Se guardan en una base SQLite y archivos locales en una carpeta seleccionada; algunos ajustes también se guardan en el dispositivo.

2. Transferencias automáticas

En el diseño actual de v35 no hay una función que envíe automáticamente bases de datos o fotos de clientes al desarrollador. La aplicación limita las conexiones de red, pero no garantiza la ausencia absoluta de transferencias realizadas por el sistema operativo o terceros.

3. Exportaciones y copias

Las copias de seguridad, restauraciones, exportaciones CSV y PDF usan ubicaciones elegidas por el usuario. Las carpetas sincronizadas con la nube o los archivos compartidos pueden transferir datos fuera del dispositivo. Borrar registros no elimina automáticamente todas las copias anteriores.

4. Correos de soporte

La aplicación abre tu programa de correo; decides si envías el mensaje. No adjunta automáticamente bases de datos ni fotos. Si escribes, pueden tratarse tu dirección, asunto, texto, adjuntos voluntarios e historial para atenderte. El buzón usa Gmail; el plazo de conservación y fundamento jurídico deben precisarse antes de publicar.

5. Alojamiento y terceros

Este sitio está preparado para GitHub Pages y no incorpora analítica, publicidad ni rastreadores propios. GitHub puede tratar datos técnicos como IP y registros de acceso. Microsoft trata los datos de adquisición de la tienda conforme a su política de privacidad.

GitHub · Microsoft

6. Responsabilidades

El taller que decide para qué recoge y conserva datos de sus clientes debe evaluar sus obligaciones. Facilitar el programa no convierte automáticamente al desarrollador en responsable de todos esos datos. Los correos de soporte son un tratamiento distinto.

7. Derechos y solicitudes

Para consultar, rectificar o solicitar la eliminación de correos enviados al soporte, escribe a carservicearchiver.support@gmail.com. Las solicitudes se evaluarán según la ley aplicable. Para registros de clientes, contacta con el taller que los gestiona.

8. Seguridad y cambios

Protege la carpeta de datos, el dispositivo y las copias. Esta política puede cambiar si cambian las funciones o los tratamientos; consulta la fecha de revisión.
