Informacje prawne i prywatność

Polityka prywatności

Ostatnia aktualizacja: 27 października 2026 · Darmowa wersja Windows · v1.0

Polityka dotyczy bezpłatnej aplikacji Car Service Archiver na Windows i tej witryny. KupferSoft jest marką niezależnego twórcy, a nie zarejestrowaną firmą. Kontakt: carservicearchiver.support@gmail.com.

1. Przechowywane dane

Nazwy klientów, kontakty, pojazdy, numery rejestracyjne, usługi, daty, przebieg, części, notatki i zdjęcia mogą zawierać dane osobowe. Są przechowywane w lokalnej bazie SQLite i plikach w wybranym folderze; niektóre ustawienia też pozostają na urządzeniu.

2. Automatyczne przesyłanie

Obecny projekt v35 nie zawiera funkcji automatycznego wysyłania bazy klientów lub zdjęć do twórcy. Połączenia sieciowe są ograniczone, ale nie gwarantuje się absolutnego braku transmisji przez system lub usługi zewnętrzne.

3. Eksport i kopie

Kopie, przywracanie, eksport CSV i PDF korzystają ze wskazanych lokalizacji. Foldery chmurowe i świadome udostępnienie mogą przesyłać dane. Usunięcie wpisu nie kasuje automatycznie wcześniejszych kopii.

4. E-maile pomocy

Aplikacja otwiera własny program pocztowy użytkownika; sam wybierasz wysłanie. Bazy i zdjęcia nie są dołączane automatycznie. Adres, temat, treść, dobrowolne załączniki i korespondencja mogą być przetwarzane w celu odpowiedzi. Skrzynka działa w Gmail; okres retencji i podstawa prawna wymagają ustalenia przed publikacją.

5. Hosting i podmioty zewnętrzne

Witryna jest przeznaczona do GitHub Pages, bez własnej analityki, reklam czy trackerów. GitHub może przetwarzać IP i dzienniki techniczne. Microsoft obsługuje dane pobierania ze Store według własnej polityki.

GitHub · Microsoft

6. Podział odpowiedzialności

Warsztat decydujący o celach i okresie przechowywania danych klientów powinien ocenić swoje obowiązki. Samo udostępnienie programu nie czyni twórcy automatycznie administratorem tych danych. Wiadomości wsparcia to odrębny proces.

7. Prawa i wnioski

W sprawie dostępu, poprawienia lub usunięcia korespondencji z pomocą napisz na carservicearchiver.support@gmail.com. Wnioski rozpatruje się według prawa. O dane klientów pytaj odpowiedni warsztat.

8. Bezpieczeństwo i zmiany

Chroń folder danych, konto na urządzeniu i kopie. Polityka może być aktualizowana; data widnieje wyżej.
